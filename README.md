# Anteiku

Monitor de recursos del sistema para la terminal, escrito en Rust, con interfaz TUI en vivo, alertas, historial y arte ASCII integrado.

> **Estado:** en desarrollo inicial (Hito M0 — Preparación). Consulta [Anteiku-documentacion.md](Anteiku-documentacion.md) para ver la arquitectura y la hoja de ruta completa.
